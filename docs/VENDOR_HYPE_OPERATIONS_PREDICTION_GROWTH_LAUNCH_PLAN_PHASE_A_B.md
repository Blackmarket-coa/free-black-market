## 1) Launch Strategy Overview

### 1.1 Goal
Launch vendor/organizer hype profiles and non-cash prediction engagement loops in a controlled way that increases:
- profile discovery and conversion,
- recurring donation participation,
- non-cash prediction retention,
- measurable trust and transparency outcomes.

### 1.2 Strategic Principles
1. **Cohort-first rollout** to tighten feedback loops and reduce operational risk.
2. **Creator-led activation** where vendors/organizers are growth channels.
3. **Engagement-to-funding loop**: hype -> donate/predict -> visibility -> repeat support.
4. **Safety-aligned growth**: no incentives that promote harmful participation patterns.

### 1.3 Phase Focus
- **Phase A launch focus:** profile awareness + donation conversion.
- **Phase B launch focus:** non-cash prediction repeat engagement and social loops.

## 2) Launch Cohorts

### 2.1 Cohort Architecture

| Cohort | Segment | Size (Initial) | Objective | Entry Criteria | Success Threshold |
|---|---|---:|---|---|---|
| C0 Pilot | High-readiness vendors/organizers | 10–20 profiles | Validate messaging + operational readiness | Complete profile, active milestones, ops dashboard baseline | >= 20% profile->action conversion |
| C1 Community Builders | Mid-size creator communities | 30–50 profiles | Drive referrals and recurring support behavior | Weekly content cadence + audience channel | >= 15% returning supporter rate (30d) |
| C2 Emerging Operators | New/long-tail vendors | 50–100 profiles | Validate onboarding scalability | Completed onboarding training + compliance checks | < 10% onboarding drop-off |
| C3 Challenger Campaigns | Time-bound milestone campaigns | 15–30 campaigns | Stress-test prediction participation loops | Clear measurable event definitions | >= 25% prediction participation among active supporters |

### 2.2 Cohort Sequencing
1. **Week 1–2:** C0 Pilot only.
2. **Week 3–4:** Add C1 after C0 quality gates pass.
3. **Week 5–6:** Add C2 with scaled onboarding ops.
4. **Week 7+:** Add C3 event-driven launches.

### 2.3 Geographic/Policy Guardrails
- Launch only in jurisdictions mapped to approved Phase A/B modes.
- Default to non-cash prediction mode for all Phase B cohorts.
- Disable prediction CTA in unsupported policy regions.

4. Milestone selection (clear measurable event for Phase B).

  - Profile visits,

## 4) Referral Mechanics

### 4.1 Referral Program Design (Phase A/B Safe)

#### Core Rules
- Referrals reward **qualified supporter actions**, not raw clicks.
- Rewards are non-cash (badges, boosts, visibility multipliers, points).
- Fraud controls apply (unique-user, device/IP heuristics, cooldown).

#### Qualified Actions
- Referred user completes profile follow + verification step.
- Referred user completes first donation above minimum threshold.
- Referred user submits first non-cash prediction position.

### 4.2 Referral Types

| Type | Referrer | Referee | Trigger | Reward |
|---|---|---|---|---|
| Creator-to-supporter | Vendor/Organizer | New supporter | First qualifying action | Creator profile boost slot + supporter badge |
| Supporter-to-supporter | Existing supporter | New supporter | First donate/predict action | Referral streak points |
| Cohort partner referral | Creator | Creator | Activated profile + first milestone | Co-marketing spotlight |

### 4.3 Anti-Fraud Safeguards
- Max rewarded referrals per user/day.
- Device/account linkage checks.
- Delayed reward unlock until anti-abuse checks clear.
- Manual review queue for abnormal referral spikes.

### 4.4 Referral Messaging CTA
- “Invite 3 supporters to unlock your profile boost week.”
- “Refer a friend who joins your prediction streak to unlock shared badges.”

### 7.1 Daily (Launch Window)
- 15-minute standup: growth, product, ops, compliance.
- Review:
  - prior day conversion funnel,
  - active incidents,

  1. KPI scorecard vs targets.
  2. Cohort progression decisions (promote/pause/hold).
  3. Funnel drop-off root cause analysis.
  4. Safety/compliance signal review.

### 7.3 Biweekly Growth Experiment Review
- Hypothesis-based experiment readouts:
  - message variants,
  - onboarding script variants,
  - referral CTA placements,
  - incentive mechanics.
- Keep/kill/iterate decisions documented with confidence level.

### 7.4 Monthly Executive Review
- Summarize:
  - growth efficiency,
  - funding outcomes,
  - trust/safety health,
  - launch readiness for expanded cohorts.
- Decide whether to expand coverage or tighten guardrails.

## 10) Operational Playbooks for Growth Team

### 10.1 Cohort Promotion Playbook
Promote cohort to next stage only if:
- P0 incident backlog = 0,
- core KPI threshold met for 2 consecutive weeks,
- compliance/safety metrics within limits.

### 10.2 Cohort Pause Playbook
Pause cohort expansion if:
- abuse flag rate breaches threshold,
- unresolved settlement disputes exceed SLA,
- donation reconciliation anomalies exceed limit.

### 10.3 Recovery Actions
- Reduce incentive intensity.
- Disable affected referral mechanic via feature flag.
- Shift traffic to trusted high-quality profiles.
- Trigger cross-functional incident review.
