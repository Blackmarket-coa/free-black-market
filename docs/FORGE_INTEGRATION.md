# FBM and Forge product/software integration

**Updated:** November 27, 2026
**Status:** Target ownership, surfaces and implementation sequence. No application feature or fee changed.

Forge houses complex technical work, customization, and advanced tools for technical creators and artists. FBM remains the authority for products, inventory, orders, listings/registry, checkout, entitlements, refunds and settlement. Advanced website/editor/integration tasks move to Forge while everyday commerce stays in the unified FBM experience.

## FBM software map changes

| Native surface | Native everyday use | Advanced Forge surface |
| --- | --- | --- |
| My Website / stall | Website link/status; manage products, orders and fulfillment | Launch/connect site, domains, templates, layout, embeds, preview/deploy, app packaging |
| My Place / equipment / appearance | Survey-driven free setup, select/pin/reorder/apply owned equipment | Author advanced portal builds, visual components, brand kits and themes |
| Creator tools / digital products | Simple upload/listing/campaign/earnings/payout management | Package advanced artifacts, preview, test, publish and deliver custom variants |
| Connected services | Connection status and routine supported actions | API/SDK/webhook setup, automation recipes, mock testing and diagnostics |
| Project/hosting status | Concise status and access to result | Deployment, logs, backups, recovery and migration |

Keep unified buyer/seller/trader direction and ordinary native tasks intact. FBM remains the registry, checkout, entitlement and settlement authority. Reuse Launch/Connect and the existing signed extension delivery contracts.


## Creator, website and portal capabilities

- Consolidate My Website Launch/Connect into Forge's advanced workspace: template selection, domains, component/SDK embeds, keys, previews and deployment. Reuse current provisioning and commerce APIs.
- Keep automatic free starter setup, ordinary pin/reorder/apply and equipment use in FBM. Author advanced portal compositions, themes, widgets, reusable brand/layout kits and licensed variants in Forge.
- Make starter blueprints for a local seller site, artist portfolio/shop and event/community project. Preview with synthetic products and reviewer access before switching to real catalog/checkout.
- Keep simple upload/listing/campaign/earnings/payout management native. Use Forge for advanced artifact validation, deterministic packaging, compatibility/slot tests, private or public distribution, and real buyer delivery.
- Support owned-asset insertion and permitted remixing with author/license lineage. Separate owned, installed, configured, enabled/equipped, updated and refunded states.
- Move technical webhook/RSS/API/SDK setup and complex automation to Forge; FBM retains connection state and ordinary controls.
- Add a permanent **Forge — Build, customize & host** entry beside account Settings/Privacy, plus My Website, Appearance/equipment, Creator tools, Connected services and project-status shortcuts.

## Shared handoff and evidence requirements

Every supported Forge capability must appear in the source app's Forge hub or have a direct link; important contextual tasks also need their own shortcut. Use a stable capability directory with ID/title, supported apps, required role, runtime/platform support, launch target, status source and return behavior.

Open the specific authorized project/tool. Preserve intent through sign-in/install/denied/unavailable/unsupported-device states; do not claim a web editor exists until implemented. Reauthorize at the destination; use short-lived authenticated references, not raw keys, tokens, private content or Vault records in URLs. Return to the original app and refresh confirmed status. Do not remove a working advanced interface until Forge parity and the complete handoff/return path are verified.

Forge authors/configures; existing domain backends enforce actual resources, access and runtime state. Deployed services continue while Forge is closed. Essential privacy/recovery/accessibility remains available independently of purchases or Forge. Optional enhancements retain one-time ownership direction; no fee or subscription change is made here.
