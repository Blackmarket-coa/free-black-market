# Backend Module Catalog

One-row inventory of every custom module under `backend/src/modules/`
(79 modules as of 2026-07-15). Paths are repo-root-relative. "Key surface"
lists the most important API route prefixes, scheduled jobs, and workflows;
"Docs" links the doc that substantively covers the module, where one exists.

Maintenance: when you add or materially change a module, update its row here
(and add a doc link if you write one). The scheduled-job inventory lives in
`backend/src/jobs/README.md`.
